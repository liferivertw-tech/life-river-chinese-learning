# Learning content and resource catalog schema — draft v0.1

Lesson: id, title, level, items[].hanzi, items[].pinyin, items[].zhuyin, items[].meaning. Later add native-language explanations, audio QA, accessibility metadata and revision history.

Resource: id, title, canonical URL, provider, topic, level, license status, review status, checkedAt. Unverified records must not be represented as verified. Link-only records must not be copied or redistributed as licensed course content.

Locale codes (15): zh-TW, en, vi, id, th, fil, ja, ko, my, km, ms, hi, fr, es, de.

BUILD 02 is a client-side prototype, not a complete localized learning platform. Speech synthesis depends on browser voice availability and has not been validated for pronunciation instruction.
