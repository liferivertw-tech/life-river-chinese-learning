# BUILD 08｜Goal → Starting Point

## Goal

Solve the homepage's primary question:

> 「我想學中文，我應該從哪裡開始？」

After a learner selects one of the eight learning goals, the homepage immediately shows a localized "Your starting point" panel and identifies the first matching stage in the eight-stage learning path.

## Behavior

- Eight goals remain unchanged.
- Selecting a goal preserves the existing focused-path behavior.
- A localized starting-point panel appears only after a goal is selected.
- The panel names the selected goal and recommended first stage.
- The action scrolls directly to that stage.
- All 15 interface locales have localized panel title, guidance sentence and action label.
- Mobile layout stacks the panel and keeps the action full width.

## Acceptance

The goal-start localization test passes and the complete 15-language desktop/mobile visual QA remains green.
