# Taiwan local-language and speech resource notes

This project distinguishes Taiwan Mandarin, regional Mandarin variation, Taiwanese Hokkien and Hakka dialect groups. A source being searchable or audible online does not automatically permit dataset download, model training, redistribution or commercial use.

## Reviewed sources (2026-10-31)

- Mozilla Common Voice 27.0 Chinese (Taiwan): CC0-1.0 dataset card; do not re-host or re-share the dataset, and do not attempt speaker identification. https://mozilladatacollective.com/datasets/cmu5wkw5i00c6o107jnm3t51u
- Taiwan Hakka Speech Database: access requires an application and agreement. Hakka Affairs Council FAQ describes commercial-use application, but the database terms prohibit redistribution/resale/transfer and restrict use to approved AI-system development. Its API has separate phased access rules. https://speech.hakka.gov.tw/Document/AboutDB https://speech.hakka.gov.tw/Document/FAQ https://www.hakka.gov.tw/chhakka/app/data/view?id=236&module=law&serno=34e1a482-5743-41c4-b15a-1a6451863a20
- NAER Taiwanese Corpus: online query tools exist; audio/text downloads have an application process. Rights for each downloaded asset must be confirmed before reuse. https://coct.naer.edu.tw/
- Academia Sinica Taiwan Mandarin Sociophonetic Corpus: research corpus covering multiple regions; corpus access and reuse terms must be checked, especially because interview metadata can be personal data. https://tmc.ling.sinica.edu.tw/corpus_list_ch/
- Taiwan Tongues: discovery and potential collaboration source; each dataset must have its own license and speaker-consent review. https://tt.ima.org.tw/

No speech corpus is copied into this repository. The site currently stores source metadata and links only.
