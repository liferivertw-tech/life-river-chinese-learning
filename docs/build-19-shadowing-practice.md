# BUILD 19 — Taiwan Mandarin shadowing practice

This module adds six practical Taiwan Mandarin sentences with Traditional Chinese, Simplified Chinese comparison, Pinyin and English reference meaning.

The learner can play a Taiwan Mandarin browser speech-synthesis sample, record their own voice with MediaRecorder, and replay the recording immediately. Microphone permission is requested only after the learner clicks Record. The recording is kept in a browser Blob in the current page session; no upload request is made. Reloading or closing the page clears the recording.

The interface controls and privacy notice are localized across all 16 supported UI languages. Sentence meanings currently use English as a reference translation; additional native-language translations can be added after review.

Scope is Taiwan Mandarin only. Taiwanese Hokkien and Hakka are not included in this product's learning content, speech recognition or pronunciation modules.
